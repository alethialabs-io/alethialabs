# Project governance

Alethia is currently founder-maintained. Borislav Borisov is the project
maintainer and final decision maker for technical direction, releases, security
responses, licensing boundaries, and accepted contributions.

## Decisions

- Routine changes are proposed through issues and pull requests.
- Architectural and security-sensitive changes require a recorded design or ADR.
- Changes to licences, CLAs, the `ee/` boundary, source offers, or trademark
  policy require maintainer approval and, where indicated, legal review.
- Community features must remain useful and buildable without enterprise code.
- Paid functionality may extend the community core through documented seams but
  must not make community installation depend on proprietary artifacts.

## Contributions

External merges remain paused until the registered company’s CLA package is
counsel-approved, activated, and enforced by the repository workflow. Afterwards,
the contribution workflow in `CONTRIBUTING.md` applies.

## Future governance

When a second regular maintainer is appointed, protected branches will require a
non-author review. Governance changes will be published in this file and will
not retroactively change licences already granted.
