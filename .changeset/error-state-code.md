`ErrorState` takes `codeVariant="bracketed"`, which sets `code` between the `[·]` mark's two brackets — `[ 404 ]` — in Space Grotesk 600 at a display rung (`text-display-sm` full page, `text-display-xs` in a panel). The code stays its own text node; the brackets are hidden from assistive technology. The default, `"mono"`, is the existing small mono line.
