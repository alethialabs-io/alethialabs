## 9 · Testability gaps

- Evidence's stage pills are buttons named only by the stage ("development" ×8, "staging" ×4…).
  The project is not in the name, so a pass, and a screen-reader user, cannot tell them apart.
- Facet options have no accessible name or selected state in the accessibility tree (#6734). A pass
  has to read `innerText` to pick an option.
- Connectors' "Group" control is a category filter (Clouds 7, Source 3…), not a group-by. The
  name suggests the other behaviour.
- The window still has to be taken out of full screen before overflow can be measured at all.
