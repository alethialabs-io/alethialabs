---
title: One-click deploy
description: Launch the self-hosted Alethia bundle on AWS or Azure from a template button, with no local tooling.
---

Create a VM on AWS or Azure from a template. The VM runs the [installer](/self-host/install) on
first boot, so you get the same bundle as every other path.

## Before you begin

- An AWS account that can create EC2 instances, security groups and Elastic IPs, or an Azure
  subscription where you can create a resource group.
- An SSH key: an EC2 key pair name on AWS, or a public key on Azure.
- Optional: a domain. Create its DNS record after the deploy, pointing at the public IP the template
  outputs.

Both templates create an x86 VM (AWS `t3.medium`, Azure `Standard_D2s_v5`) running Ubuntu 24.04, with
ports 22, 80 and 443 open.

## Deploy on AWS

<a href="https://console.aws.amazon.com/cloudformation/home#/stacks/create/review?templateURL=https://raw.githubusercontent.com/alethialabs-io/alethialabs/main/deploy/oneclick/aws-cloudformation.yaml&stackName=alethia"><img src="/docs/img/aws-launch-stack.png" alt="Launch Stack" /></a>

1. Select **Launch Stack**.
2. Fill in the parameters: `KeyName` is required. `Domain`, `AcmeEmail`, `InstanceType`,
   `AllowedSshCidr` and `VolumeSize` are optional. `AllowedSshCidr` defaults to `0.0.0.0/0`, so
   narrow it to your own address range.
3. Create the stack, and read `PublicIp` from its **Outputs**.

The template is
[`deploy/oneclick/aws-cloudformation.yaml`](https://github.com/alethialabs-io/alethialabs/blob/main/deploy/oneclick/aws-cloudformation.yaml).
From the AWS CLI:

```bash
aws cloudformation deploy --stack-name alethia \
  --template-file deploy/oneclick/aws-cloudformation.yaml \
  --parameter-overrides Domain=alethia.example.com AcmeEmail=you@example.com KeyName=my-key \
  --capabilities CAPABILITY_IAM
```

## Deploy on Azure

<a href="https://portal.azure.com/#create/Microsoft.Template/uri/https%3A%2F%2Fraw.githubusercontent.com%2Falethialabs-io%2Falethialabs%2Fmain%2Fdeploy%2Foneclick%2Fazure-arm.json"><img src="/docs/img/deploy-to-azure.svg" alt="Deploy to Azure" /></a>

1. Select **Deploy to Azure**.
2. Fill in `sshPublicKey`, and optionally `domain`, `acmeEmail`, `adminUsername`, `vmSize` and
   `location`.
3. Create the deployment, and read `publicIp` from its **Outputs**.

The template is
[`deploy/oneclick/azure-arm.json`](https://github.com/alethialabs-io/alethialabs/blob/main/deploy/oneclick/azure-arm.json).
From the Azure CLI:

```bash
az deployment group create --resource-group alethia-cp \
  --template-file deploy/oneclick/azure-arm.json \
  --parameters domain=alethia.example.com acmeEmail=you@example.com \
               sshPublicKey="$(cat ~/.ssh/id_ed25519.pub)"
```

## Add a domain later

With the domain left empty, the console serves plain HTTP at the public IP. To add HTTPS, point the
domain's DNS record at the IP, SSH to the VM, set `ALETHIA_DOMAIN`, `NEXT_PUBLIC_APP_URL` and
`BETTER_AUTH_URL` in `/opt/alethia/.env`, and run `sh /opt/alethia/deploy/install.sh` again.

## Check that it worked

Open `http://<public IP>` or your domain. The sign-in page loads. First boot takes a few minutes
while Docker installs and the images pull. Then follow [Sign in](/self-host/install#sign-in).
