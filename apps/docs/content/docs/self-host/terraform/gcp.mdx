Provision a Compute Engine VM for the control plane with `infra/cp-gcp`. Web traffic comes through a
Cloudflare Tunnel, and SSH is open only to Google's Identity-Aware Proxy (IAP). Read
[OpenTofu per cloud](/self-host/terraform) first.

## What it creates

- An `e2-standard-2` (2 vCPU, 8 GB) running Ubuntu 24.04, with a 30 GB `pd-balanced` boot disk,
  Shielded VM (secure boot and vTPM), and its own least-privilege service account.
- A firewall rule that allows SSH only from the IAP range `35.235.240.0/20`.
- An ephemeral external IP, for outbound traffic only.
- The Cloudflare Tunnel, and proxied CNAME records for the apex and `www`.

At the default region `europe-west4`, on demand, this costs about $57 a month (Infracost).

## Before you begin

- A GCP project with the Compute Engine and IAP APIs turned on.
- Application Default Credentials: `gcloud auth application-default login`. Do not use a
  service-account key file.
- The Cloudflare token, zone ID and account ID.

## Apply

```bash
cd infra/cp-gcp
cp backend.hcl.example backend.hcl
cp terraform.tfvars.example terraform.tfvars   # gcp_project, gcp_region, gcp_zone, cloudflare_*
tofu init -backend-config=backend.hcl
tofu plan -out=tfplan
tofu apply tfplan
```

Variables you may change: `machine_type` (must be x86), `boot_disk_size`, `gcp_region`, `gcp_zone`.

## Check that it worked

```bash
gcloud compute ssh alethia-cp --zone <zone> --tunnel-through-iap
```

`/opt/alethia` holds the repository.
