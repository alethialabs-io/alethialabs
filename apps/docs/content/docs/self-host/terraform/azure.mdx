Provision an Azure VM for the control plane with `infra/cp-azure`. It has no inbound rule: web
traffic comes through a Cloudflare Tunnel, and you run commands through the Azure control plane.
Read [OpenTofu per cloud](/self-host/terraform) first.

## What it creates

- A `Standard_D2s_v5` (2 vCPU, 8 GB, x86 Gen2) running Ubuntu 24.04, with a 30 GB StandardSSD OS
  disk, Trusted Launch (secure boot and vTPM), a system-assigned managed identity, and boot
  diagnostics for the Serial Console.
- A resource group, a virtual network and a subnet.
- A network security group with no inbound rules.
- A Standard public IP, for outbound traffic only.
- The Cloudflare Tunnel, and proxied CNAME records for the apex and `www`.

At the default location `westeurope`, on demand, this costs about $90 a month (Infracost).

## Before you begin

- An Azure subscription, and Contributor on it. Sign in with `az login` instead of a
  service-principal secret.
- The Cloudflare token, zone ID and account ID.

## Apply

```bash
cd infra/cp-azure
cp backend.hcl.example backend.hcl
cp terraform.tfvars.example terraform.tfvars   # location, cloudflare_*
az login
export ARM_SUBSCRIPTION_ID=<subscription id>
tofu init -backend-config=backend.hcl
tofu plan -out=tfplan
tofu apply tfplan
```

Variables you may change: `vm_size` (must be x86 Gen2, for Trusted Launch), `os_disk_size`,
`location`.

## Check that it worked

Run a command on the VM, or open its Serial Console:

```bash
az vm run-command invoke -g <resource group> -n alethia-cp --command-id RunShellScript --scripts 'ls /opt/alethia'
az serial-console connect -g <resource group> -n alethia-cp
```
