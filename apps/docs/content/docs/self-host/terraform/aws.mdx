Provision an EC2 instance for the control plane with `infra/cp-aws`. It has no open port: web
traffic comes through a Cloudflare Tunnel, and you reach a shell through SSM Session Manager. Read
[OpenTofu per cloud](/self-host/terraform) first.

## What it creates

- An EC2 `t3.large` (2 vCPU, 8 GB) running Ubuntu 24.04, with an encrypted 60 GB gp3 root volume and
  IMDSv2 required. It runs in the account's default VPC, with a public IP for outbound traffic only.
- A security group with no inbound rules.
- An IAM role and instance profile with only `AmazonSSMManagedInstanceCore`.
- The Cloudflare Tunnel, and proxied CNAME records for the apex and `www`.

At the default region `eu-west-1`, on demand, this costs about $72 a month (Infracost). A
`t3.medium` costs about half, with 4 GB of memory.

## Before you begin

- AWS credentials for the target account. Use a short-lived source, such as
  `aws sso login --profile <profile>`, instead of an access key.
- The Cloudflare token, zone ID and account ID.

## Apply

```bash
cd infra/cp-aws
cp backend.hcl.example backend.hcl
cp terraform.tfvars.example terraform.tfvars   # cloudflare_*, domain, aws_region
export AWS_PROFILE=<profile>
tofu init -backend-config=backend.hcl
tofu plan -out=tfplan
tofu apply tfplan
```

Variables you may change: `instance_type` (must be x86), `root_volume_size`, `aws_region`.

## Check that it worked

Open a shell on the instance. No SSH port is needed:

```bash
aws ssm start-session --target <instance id>
```

`/opt/alethia` holds the repository.
