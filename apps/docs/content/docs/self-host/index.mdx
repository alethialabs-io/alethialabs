---
title: Self-host
description: Run the whole Alethia platform on your own VM or Kubernetes cluster, then configure, upgrade and back it up.
---

A self-hosted Alethia is one Docker Compose bundle: the console, the docs, Postgres, an
S3-compatible object store (SeaweedFS), a runner, and Caddy for HTTPS. It runs on a VM in any cloud
or on your own hardware, and needs no managed database or object store.

## Choose how to install

| Path | Use it when | Page |
| --- | --- | --- |
| Installer | You have a Linux VM and a domain. One command. | [Install on a VM](/self-host/install) |
| One-click | You want AWS or Azure to create the VM from a template. | [One-click deploy](/self-host/one-click) |
| OpenTofu | You want the VM, its firewall and a Cloudflare Tunnel as code. | [OpenTofu per cloud](/self-host/terraform) |
| Helm | You already run Kubernetes. | [Helm chart](/self-host/helm) |

The one-click templates run the same installer. The Helm chart deploys the same images.

## Then

1. [Configure](/self-host/configuration) sign-in providers, storage and the client-IP header.
2. [Set up email](/self-host/email), so sign-in codes reach your users.
3. [Upgrade and back up](/self-host/upgrading) on a schedule.

Optional: [turn on Enterprise](/self-host/enterprise-setup), [run more console
replicas](/self-host/scaling-out), or [run a managed runner
fleet](/self-host/managed-provisioning) that provisions into your users' clouds.

## What is in the bundle

| Service | Role |
| --- | --- |
| `app` | The console: web app and API |
| `preflight` | Checks that every instance secret is set and is not a placeholder, then exits |
| `migrate` | Applies database migrations, then exits. `app` starts after it. |
| `docs` | These docs, at `/docs` |
| `blog` | News and changelog, at `/news` |
| `postgres` | The database |
| `seaweedfs` | Object storage for OpenTofu state and plan files |
| `runner` | Runs plan and apply jobs, with the credentials you give it |
| `caddy` | The only service with open ports (80 and 443). Gets TLS certificates. |
| `pgweb` | Optional database browser (`tools` profile) |
| `openfga` | Optional authorization engine for Enterprise (`enterprise` profile) |
