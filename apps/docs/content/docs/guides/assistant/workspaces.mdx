---
title: Use a workspace
description: Chat with Elench about the whole organization or about one project, each workspace with its own chats, knowledge and memory.
---

Keep chats about one project apart from chats about the whole organization. Each workspace has its
own chats, knowledge and memory, and nothing moves between them.

| Workspace | Scope | Grounded by |
| --- | --- | --- |
| **Organization** | The whole organization, with the organization-wide tools | Organization instructions and knowledge |
| **Project** | One [project](/guides/design-project) | Organization instructions and knowledge, then the project's own, then live facts about the project: its identity, environments and recent jobs |

## Before you begin

- The assistant is available. See [Ask the assistant](/guides/assistant).

## Steps

1. To chat about the organization, select **Ask AI** on an organization page, such as **Overview**.
2. To chat about a project, select **Ask AI** on one of the project's pages or on its canvas.

The workspace follows where you open the assistant. The switcher in the panel's header moves between
chats in the current workspace, not between workspaces.

## What each workspace keeps apart

- **Chats.** You see only the current workspace's chats.
- **Knowledge.** The knowledge panel edits the current workspace's
  [instructions and documents](/guides/assistant/knowledge). Every chat in a project inherits the
  project's, and they never reach organization chats or other projects.
- **Memory.** The organization has one memory and each project has its own, kept under the
  organization's and never shared with another project. See
  [Agent runtime](/concepts/elench/agent-runtime).
- **Tools.** A project's tools are not offered in an organization chat.

Chats, knowledge and instructions belong to you. Elench reads and writes only what you own, so a
teammate cannot see them.

## Check that it worked

Open the assistant from a project page: the chat list shows only that project's chats, and the
knowledge panel shows the project's **Already known** facts.
