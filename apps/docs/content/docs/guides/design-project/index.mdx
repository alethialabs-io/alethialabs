---
title: Design a project
description: The tasks for designing an environment on the canvas, in the order you usually do them.
---

You design an environment on the **Architecture** canvas: you add resources as cards, set each one
in the inspector, then review a plan and deploy it. Find your task below.

## Lay out the environment

| Task | Page |
| --- | --- |
| Find your way around the canvas, connect resources, and deploy | [Use the canvas](/guides/design-project/the-canvas) |
| Rename, configure, duplicate or delete a resource | [Use the inspector](/guides/design-project/node-inspector) |
| Set the project name, stage and region | [Set the project basics](/guides/design-project/project-basics) |
| Choose a new or an existing network | [Configure the network](/guides/design-project/network) |
| Size the Kubernetes cluster | [Configure the cluster](/guides/design-project/cluster) |
| Add node pools, labels and taints | [Add node pools](/guides/design-project/node-pools) |
