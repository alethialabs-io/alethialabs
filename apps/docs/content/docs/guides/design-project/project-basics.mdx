Set the project's name, the stage of its default environment, and its region.

## Before you begin

- You have a project open on the [canvas](/guides/design-project/the-canvas). The cloud account
  was chosen when you created the project.

## Steps

1. Select the **Project** card. The inspector opens with two groups, **General** and **Placement**.
2. Under **General**, set **Project name**. Use up to 100 characters, with at least one letter or
   number. Alethia derives a URL-safe identifier from it, which it also uses to name cloud
   resources and the OpenTofu state.
3. Under **General**, choose **Environment**:

   | Stage | Use it for |
   | --- | --- |
   | **Development** | Short-lived, low-cost defaults |
   | **Staging** | A copy of production for testing |
   | **Production** | Live traffic, with durable sizing |

4. Under **Placement**, choose the **Region**. The list shows your cloud's regions, grouped by
   geography.

The stage belongs to the environment, not to the project. A project can have several environments,
each with its own stage and its own OpenTofu state.

Alethia runs OpenTofu 1.11.4. You cannot choose another version on the canvas.

## Check that it worked

The **Project** card shows the region and the stage. The changes bar counts the edit as a pending
change.
