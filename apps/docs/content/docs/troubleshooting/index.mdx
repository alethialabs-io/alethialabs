## First checks

- **Read the job log.** Most deploy and destroy failures name their cause there. Open the job from
  **Jobs**, or run `alethia jobs logs --latest`.
- **Read the CLI's exit code.** It names the class of failure. See [Exit codes](/agents/cli#exit-codes).
- **Check the limits.** A refusal that names a number is often a ceiling. See [Limits](/reference/limits).

If nothing here helps, open a case from **Support** in the console, with the job ID and the exact
message.
