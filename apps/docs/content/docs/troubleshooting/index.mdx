## Before you start

- **Read the job log.** Most deploy and destroy failures name their cause in the log. Open the job
  from **Jobs** in the sidebar, or run `alethia jobs logs --latest`.
- **Check the CLI's exit code.** Every CLI failure exits with a code that names its class. The table
  is in [Exit codes](/agents/cli#exit-codes).
- **Check the limits.** A refusal that names a number is often a ceiling. See [Limits](/reference/limits).

If a page here does not help, open a support case from **Support** in the console's sidebar, and include the job
ID and the exact message.
