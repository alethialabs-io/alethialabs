# Tutorials

A tutorial is a lesson. It has one path, tells you exactly what to type, and ends with something
running that you can look at. Use a tutorial the first time you use Alethia. To do a specific task,
use the [how-to guides](/guides). To understand why the product works the way it does, read the
[concepts](/concepts).

Follow each step exactly. If a step does not give the result the page says it gives, the page has a
bug. Please report it.

## Available tutorials

**[Deploy Online Boutique to three environments](/tutorials/online-boutique)**: build one cluster
that hosts three environments at three isolation levels, and deliver a twelve-service shop into two
of them. About 40 minutes, most of it waiting for the cluster. Tested on Hetzner Cloud, AWS, and
Google Cloud.

## Before you start any of them

- [Install the CLI](/get-started/install-the-cli) and run `alethia login`.
- Have an account on a supported cloud, with permission to create clusters and networks.

<Callout type="warn">
  Tutorials **create real infrastructure that costs money.** Each one ends with a teardown step, and
  you are not finished until you run it.
</Callout>
