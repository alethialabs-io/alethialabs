The console is Alethia's web control plane. The hosted console is at [alethialabs.io](https://alethialabs.io). It provides a visual interface for configuring infrastructure, managing [cloud identities](/guides/connectors), monitoring [jobs](/guides/jobs), and viewing provisioned clusters — all from the browser. Alethia is the platform; the Console is the web app you drive it from.

## Start here

To go from a new account to a running cluster in the console, follow the quickstart for your
cloud: [AWS](/get-started/quickstart-aws), [GCP](/get-started/quickstart-gcp),
[Azure](/get-started/quickstart-azure), or [Hetzner](/get-started/quickstart-hetzner).

Every organization's data is kept apart from every other organization's. For how, see
[Security](/concepts/security).
