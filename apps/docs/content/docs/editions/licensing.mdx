---
title: Licensing
description: How an Enterprise licence turns on entitlements in a self-hosted Alethia, how it is checked, and what happens when it ends.
---

An <Enterprise>Enterprise</Enterprise> licence turns on a fixed set of entitlements. The product
reads those entitlements; nothing else in the code asks whether the instance is licensed. To install
a licence, see [Enterprise setup](/self-host/enterprise-setup).

## Entitlements

| Entitlement | Turns on |
|---|---|
| `organizations` | Multi-member organizations, members, invitations, the organization switcher |
| `teams` | Teams, and grants to a team |
| `sso` | SSO sign-in over OIDC and SAML |
| `customRoles` | The custom-role editor and the access portal |
| `activityExport` | CSV export of the Activity log. Viewing it is free. |
| `alerting` | Alert policies, channels and the delivery log |
| `advancedAlerting` | Alert rules on security events from the Activity log |
| `agentPolicy` | Agent policy: a different approver, and the OAuth client allow-list |
| `byoRunners` | Bring-your-own runners on the hosted service. A self-hosted operator always has them. |
| `managedPools` | Managed runner pools on the hosted service. A self-hosted operator always has them. |

A licence also carries scheduling quotas: concurrent jobs, priority, included runner minutes and
Activity retention.

Without a licence every entitlement is off, and the console is Community: one personal
organization, the four built-in roles, and an Activity log you can browse but not export.

## How the licence is checked

The licence is a signed token that Alethia Labs issues, set as `ALETHIA_LICENSE_KEY`. The console
checks it offline against public keys built into the published image, and sends nothing to Alethia
Labs. A licence that is missing, malformed, expired past its grace period, or signed by another key
grants nothing. The console still starts, as Community.

`ALETHIA_EDITION` decides whether the Enterprise package loads: `community` never loads it,
`enterprise` (the published image's setting) requires it, and `auto` loads it when present. The
open-source code never imports the package directly, so a build without it is a complete Community
product. See [the open-core architecture](https://github.com/alethialabs-io/alethialabs/blob/dev/docs/contributing/authorization.md).

## When a licence ends

A licence keeps granting for its grace period after the end date: 30 days unless the licence states
another period. Then the instance goes back to Community. No data is deleted, and members keep their
data, but Enterprise-only operations stop until a valid licence is installed. No restart is needed.

<Callout type="warn">
  Running Enterprise in production needs a commercial licence. The `ee/` directory is source-visible
  under its own licence, not AGPL. Running Community never needs one.
</Callout>
