<Community>Community</Community> is free and open source (AGPL-3.0).
<Enterprise>Enterprise</Enterprise> needs a licence. On the hosted service, each organization's plan
decides which of these it has; the [pricing page](https://alethialabs.io/pricing) lists them.

## Authorization

The permission model is the same in both editions.

| Capability | Community | Enterprise |
|---|:--:|:--:|
| Policy decision point: every action checked the same way | ✅ | ✅ |
| Built-in roles: owner, admin, operator, viewer | ✅ | ✅ |
| Per-resource grants, inherited from organization to project | ✅ | ✅ |
| Explicit deny, with exceptions | ✅ | ✅ |
| Grants of a single permission, not only a role | ✅ | ✅ |
| Row-Level Security between tenants | ✅ | ✅ |
| Activity log of every action and refusal | ✅ | ✅ |
| Postgres authorization engine | ✅ | ✅ |
| OpenFGA engine (optional) | — | ✅ |

## Organizations and people

| Capability | Community | Enterprise |
|---|:--:|:--:|
| A personal organization with one owner | ✅ | ✅ |
| Multi-member organizations, invitations, organization switcher | — | ✅ |
| Teams, with grants to a team | — | ✅ |
| Custom roles: the permission-matrix editor | — | ✅ |
| Access portal: allow or deny, for a user or a team, at any scope | — | ✅ |
| Email codes and GitHub, Google, GitLab and Bitbucket sign-in | ✅ | ✅ |
| SSO over OIDC or SAML | — | ✅ |

## Activity, alerts and agents

| Capability | Community | Enterprise |
|---|:--:|:--:|
| Browse the Activity log | ✅ | ✅ |
| Export the Activity log as CSV | — | ✅ |
| Alert policies, channels and the delivery log | — | ✅ |
| Alert rules on security events from the Activity log | — | ✅ |
| Agent access switch, and no agent applies to production | ✅ | ✅ |
| Agent policy: a different approver, and an OAuth client allow-list | — | ✅ |

## Runners

| Capability | Self-hosted, either edition | Hosted service |
|---|:--:|:--:|
| Bring-your-own runners | ✅ | By plan |
| A managed runner fleet with warm pools | ✅ | — |

A self-hosted operator always manages runners and pools. See
[Managed provisioning](/self-host/managed-provisioning).
