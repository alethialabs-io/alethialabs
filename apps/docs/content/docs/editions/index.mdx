---
title: Editions
description: Alethia's two editions — the open-source Community edition and the licensed Enterprise edition — and where the line between them is.
---

Alethia is open-core. Both editions are built from the same code:

- <Community>Community</Community> is open source under AGPL-3.0, and free. It is the complete
  product for one person or one shared account, with no licence key.
- <Enterprise>Enterprise</Enterprise> adds what many people in one organization need:
  multi-member organizations, teams, SSO, custom roles, the access portal, Activity export, and the
  optional OpenFGA engine. It needs a licence.

You can self-host either edition. Where Alethia runs and which edition it runs are separate choices.
On the hosted service, each organization's plan decides what it can use.

## Where the line is

Everything you need to design, deploy and govern infrastructure is in Community, including the
permission model itself: built-in roles, per-resource grants, deny rules, Row-Level Security between
tenants, and the Activity log. Enterprise adds the machinery for organizations of people: inviting
and grouping them, signing them in with SSO, writing custom roles, and deciding access at scale.

The open-source code never depends on the Enterprise package and runs without it. See
[the open-core architecture](/concepts/access-control/open-core).
