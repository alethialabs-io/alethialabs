# `@alethia/enterprise-api`

This Apache-2.0-licensed package defines the minimal registration protocol
between the AGPL Community application and an optional extension package. It
contains no Enterprise implementation and grants no rights to `ee/`.
The full Apache 2.0 text is at
[`LICENSES/Apache-2.0.txt`](../../LICENSES/Apache-2.0.txt).

Keeping the protocol neutral makes the build boundary explicit without claiming
that dynamic loading determines the copyright status of a combined program.
