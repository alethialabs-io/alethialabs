# Vault keys that MUST exist in `alethia/prod/env` for a production deploy to be valid.
#
# ONE key per line. `#` comments and blank lines are ignored. This file is the single source of
# truth: `.github/workflows/deploy-console.yml`'s `preflight` job checks every key here against the
# live vault BEFORE any image is built, and also asserts that the deploy script's own inline
# `[ -n "$X" ] || … exit 1` assertions (`scripts/ci/deploy-console-assemble-env.sh`) correspond
# exactly to this list — so the two cannot drift.
#
# WHY THIS FILE EXISTS
#
# #2375 added two such assertions for keys that were never populated. Nothing in CI reads the
# vault, so it passed every check and only failed after reaching `main` — and it failed AFTER ~20
# minutes of image builds, at the very last step. Production could not deploy for two weeks.
#
# Adding a key here is a deliberate, reviewable act. Adding an assertion to the deploy WITHOUT
# adding it here fails the preflight, which is the point: the list and the gate move together.
#
# A key that is merely *nice to have* does NOT belong here — an absent key that the app has a
# documented default for is not a deploy blocker. Only list what genuinely must not be empty.

# The box to deploy to. Written by infra-cp-hetzner on provision.
DEPLOY_HOST

# Public company phone. Legally required on the Bulgarian company-information surface (#2375).
ALETHIA_PUBLIC_PHONE

# Transactional email has NO unconditional key. The vault selects the transport (EMAIL_PROVIDER,
# unset = ses) and each transport needs its own keys, which this unconditional list cannot express.
# scripts/ci/check-email-provider-keys.sh is that conditional gate, run by the preflight and again
# by the deploy (infra/email-ses-account/README.md). packages/email/src/config.ts also THROWS in
# hosted mode when the selected provider has no credentials, so a gap breaks email-OTP sign-in
# loudly rather than degrading quietly.

# Instance secrets docker-compose.yml references as `${NAME:?…}`, with no default (#6803). The
# deploy emits an absent key as an empty value, which compose refuses on the box; listing them
# here refuses in the preflight, before any image is built. The list of every instance secret is
# deploy/selfhost/secrets.manifest; only the ones the shared compose file requires are gated here.
